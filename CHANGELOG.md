# Changelog

All notable changes to the "image-webify" extension will be documented in this file.

## [1.0.0] - 2026-02-11

### Added
- **WebP Support**: Convert images (PNG, JPG, GIF, TIFF) to WebP format directly from the Explorer context menu.
- **AVIF Support**: Convert images (PNG, JPG, GIF, TIFF) to Avif format directly from the Explorer context menu.
- **Multi-select**: Convert multiple images at once using parallel processing for better performance.
- **Quality Settings**: Choose between preset quality levels or use global defaults from settings.
- **Global Configuration**: Customize default quality and toggle "ask for quality" prompts in VS Code settings.
